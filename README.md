# naobot

naobot 是运行在 QQ 群中的 Lagrange.Milky 机器人，提供 AI 问答、群聊互动、趣味游戏、定时提醒和反诈防护。机器人只处理配置的目标群，命令统一使用 `@nao`，不使用旧的斜杠命令。

## 使用范围和权限

- 只有配置的目标群会响应机器人事件，其他群不会处理。
- 普通成员可以使用公开功能、AI 问答和游戏。
- 关键词库、定时提醒、反诈记录和违规词黑名单只允许群主、群管理员或配置的管理员 QQ 号使用。
- 管理员消息默认不会进入自动反诈处罚流程。
- 机器人自己的消息不会触发反诈处罚、主动接梗或复读。
- `@nao 帮助` 仍显示机器人内置的常用菜单，帮助内容保持运行时代码中的原样；README 补充列出完整功能和用法。

## 基础功能

| 用法 | 功能 |
| --- | --- |
| `@nao 帮助` | 查看机器人内置菜单 |
| `@nao 状态` | 查看机器人是否在线 |
| `@nao 关于` | 查看机器人介绍 |
| `你好` | 获取固定问候 |

## AI 问答

- 发送 `@nao 你的问题` 直接提问，不需要额外输入“问”。
- 每个 QQ 号有 10 秒 AI 请求冷却，回答超过 1500 个字符会自动截断。
- AI 会自动清理 Markdown，并在回答合适时发送一张已标注场景的表情；AI 失败时仍会返回简短提示或纯文字回答。
- 支持开心、无语、委屈、震惊、吃瓜、摸鱼、加班、鼓励、道歉、晚安、拒绝、阴阳怪气、问候、思考、庆祝和好笑等表情场景。

### 小火人主动接梗

- 普通群聊无需 `@nao`，机器人会结合最近消息判断是否适合接话。
- 只有明显的玩笑、梗、反差或自然接话点才会回复一到三句；普通陈述、技术讨论、严肃求助、争吵、广告和链接通常保持沉默。
- 遇到近期或陌生网络梗时，机器人可能使用联网搜索核实后再决定是否回复。
- 每个群最多每 8 秒判断一次，主动回复后冷却 45 秒。

### 多人复读

- 30 秒内有 3 名不同成员发送完全相同的普通纯文本时，机器人会原样复读一次。
- 图片、链接、回复、提及、命令、固定回复和关键词回复不会触发复读。

## 关键词回复

管理员使用以下命令维护关键词库：

```text
@nao 关键词
@nao 关键词 添加 触发词=回复内容
@nao 关键词 删除 触发词
@nao 关键词 列表
```

普通成员发送与触发词完全一致的消息时，机器人会自动回复对应内容。关键词最多 50 条，触发词最长 30 个字符，回复最长 500 个字符。

## 实验室问答

在 `data/lab_faq.json` 中保存问答，格式为：

```json
{
  "怎么预约实验室仪器？": "登录预约系统，选择仪器和空闲时段后提交。"
}
```

成员发送 `@nao 完整问题` 时，机器人会直接返回匹配答案，不调用 AI。文件修改后无需重启；编辑过程中 JSON 暂时无效时，机器人继续使用上一份有效内容。`@nao 帮助` 会自动追加当前 FAQ 问题索引。格式示例见 `examples/lab_faq.example.json`。

## 表情和 Emoji

- `@nao 表情包制作`：查看表情包模板。
- 具体模板可以按模板要求发送，例如 `@nao 摸 @成员`。
- `😂+🥺`：合成两个 EmojiMix。
- EmojiMix 自动识别已关闭，避免普通聊天误触发。
- AI 表情只在 AI 成功回答时发送，不用于反诈、管理、固定回复或关键词回复。
- 私有表情的场景和启用状态在 `data/reaction_catalog.json` 中维护；未标注或未启用的素材不会被 AI 选中，格式示例见 `examples/reaction_catalog.example.json`。

## 新成员欢迎

新成员加入目标群后，机器人会 `@` 对方并发送欢迎消息；机器人自己加入群时不会触发欢迎。

## 定时提醒

以下命令只允许管理员使用：

```text
@nao 定时 2026-08-10 21:00 提交作业
@nao 定时任务，本周五 09:00 提醒部署网站
@nao 每天晚上九点提醒我写 donelist
@nao 定时列表
@nao 取消定时 任务编号
```

- 支持一次性、每天和每周提醒，时间按北京时间解释；没有写时刻时默认 `09:00`。
- 自然语言提醒由 DeepSeek 解析，只有管理员可以创建。
- 到期后机器人会在原群 `@` 创建者并发送提醒。
- 每群最多保存 50 条待发送提醒，内容最长 500 个字符；任务保存在 `data/reminders.sqlite3`，重启后不会丢失。

## 趣味游戏

### 今日人品

```text
@nao 今日人品
@nao 本周人品
@nao 本月人品
@nao 平均人品
```

### 猜成语

发送 `@nao 猜成语` 开始四字成语猜测。开始后直接发送答案；发送 `提示` 获取提示，发送 `结束` 结束本局。

### 人生重开

- `@nao 人生重开`：开始人生重开模拟。
- `@nao 人生重开 随机`：自动随机选择属性。
- 开始后按照机器人提示直接回复选择。

### 猜人物

- 发送 `@nao 猜人物` 开始 DeepSeek 二十问。
- 开始后回复 `是`、`否`、`不知道`、`可能` 或 `可能不是`。
- 发送 `退出` 或 `结束` 终止本局；最多提问 20 次，5 分钟无操作自动失效。

## 自动反诈防护

自动反诈只处理普通成员。命中后会优先撤回原消息，记录违规次数，并 `@` 发送者提示原因；不会踢人或禁言。

### 自动识别内容

- 文字中的刷单、垫付返现、解冻金、安全账户、共享屏幕转账、代收验证码、保本投资、裸聊等高风险话术。
- 论文代写、盲审修改、答辩修改、包通过、不过退款等组合广告。
- 兼职、临时工、日结、高佣、高回报、无门槛收益等诱导。
- 微信、QQ 群、扫码、私聊等站外引流。
- 转账、汇款、定金、充值、银行卡、验证码、贷款等资金诱导。
- 可疑网址和引导点击链接的话术。
- 普通成员发送的 QQ 好友名片、群名片和冒充重要通知。
- 图片二维码和图片 OCR 文字。
- 视频二维码和视频画面中的 OCR 文字。

### 图片和视频检测

- 图片最大 8 MB，使用 OpenCV 检测二维码，使用本地 RapidOCR 识别文字。
- 视频最大 48 MB，检测时按 `0 秒、5 秒、10 秒...` 每次提取一帧。
- 视频逐帧 OCR；当前帧命中二维码、黑名单、重要通知或诈骗规则后，立即停止后续抽帧。
- 视频流入临时文件处理，检测完成或失败后自动删除，不保留视频内容。
- 下载、解码或 OCR 失败只记录日志并跳过，不会仅凭失败处罚成员。

### 反诈管理命令

```text
@nao 反诈状态
@nao 反诈记录 @成员
@nao 反诈记录 QQ号
@nao 清除违规 @成员
@nao 清除违规 QQ号
```

### 违规词黑名单

管理员可以维护持久化黑名单：

```text
@nao 添加违规 违规成员发送的完整内容
@nao 添加违规                  # 回复违规消息后发送
@nao 违规词列表
@nao 删除违规词 词条
```

AI 只提供候选短语，本地代码会校验短语确实存在于原文中，并过滤过于宽泛的词。黑名单同时用于文字、图片 OCR 和视频 OCR，保存在 `data/fraud_keywords.json`。

## 当前不提供的操作

`@nao 踢出`、`@nao 禁言` 和手动 `@nao 撤回` 已停用。机器人只会在自动反诈命中时撤回对应违规消息。

完整功能目录见 [FEATURES.md](FEATURES.md)。
